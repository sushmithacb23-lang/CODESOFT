# CodSoft UI/UX Internship – Task 3: Weekly Newsletter Design

## 🎯 Objective
Design an email newsletter layout that highlights updates, promotions, and call-to-action buttons clearly.

## 🧩 Tools Used
- Figma
- FlatIcon
- Google Fonts

## 🧠 Design Process
1. Planned grid layout with clear content blocks.
2. Focused on CTA visibility and branding consistency.
3. Chose warm color palette to increase engagement.
