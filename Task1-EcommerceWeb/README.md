# CodSoft UI/UX Internship – Task 1: E-Commerce Web Design

## 🎯 Objective
Design a clean and modern e-commerce website interface focusing on product browsing and easy checkout flow.

## 🧩 Tools Used
- Figma
- ColorHunt (for color palette)
- Google Fonts

## 🧠 Design Process
1. Defined layout with a grid system.
2. Created wireframes for homepage and product view.
3. Used minimal color scheme and typography for readability.
4. Added responsive design concepts.
