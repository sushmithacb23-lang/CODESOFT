# CodSoft UI/UX Internship – Task 2: Restaurant Menu App

## 🎯 Objective
To design a mobile app for browsing food menus, placing orders, and viewing details in a visually pleasing way.

## 🧩 Tools Used
- Figma
- Material Design Icons
- FontPair

## 🧠 Design Process
1. Created wireframes for the home and product detail screens.
2. Used soft colors and modern illustrations.
3. Designed easy navigation tabs for users to explore menu items.
